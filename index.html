Interview Memory Bank

面试素材库

提前把经历翻译成面试官听得懂的问题、行动和结果。以后写简历会轻松很多。

STAR

一次困难调试

  • S：在什么场景下出现问题？影响范围是什么？
  • T：你负责定位哪一层？硬件、驱动、算法还是通信？
  • A：你用了哪些日志、波形、断点、对比实验？
  • R：最终指标提升多少？有没有沉淀文档或工具？
Project Pitch

一个完整项目

用“目标 → 架构 → 关键模块 → 难点 → 验证 → 复盘”六句话讲完，别一上来陷进代码细节。

Questions

高频追问清单

  1. 为什么不用更简单或更成熟的方案？
  2. 这个 Bug 你怎么排除偶然性？
  3. 你的优化有没有量化对比？
  4. 如果时间更多，你会怎么重构？
